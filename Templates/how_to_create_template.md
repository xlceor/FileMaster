#  How to Create Custom Excel Templates

To create a professional custom Excel report, follow these steps:

1. **Design your template**: Open Excel and create a file with your preferred look, logo, custom fonts, colors, and sheet structure.
2. **Naming**: Name the sheets in your template exactly as the application expects:
   - "Encontrados" (Found)
   - "Faltantes" (Missing)
   - "Sobrantes" (Extra)
   - "Resumen" (Summary)
3. **Usage**: Place your custom `.xlsx` file in the `Templates/` directory or anywhere you like.
4. **Select**: In the FileMaster application's Configuration panel, select your template file to apply your corporate branding and layout to the generated comparison reports.

The application will automatically inject the comparison data into your designated sheets, preserving all your original styling, logos, and layout!
